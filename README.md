# Unsolved Problems

자연과학, 수학, 공학, 의학, 인지과학과 사회과학의 미해결 문제를 여러 축으로 탐색하는 한·영 공개 카탈로그입니다.

- 사이트: <https://eljja.github.io/UnsolvedProblems/>
- 기본 데이터: [`data.js`](./data.js)
- 확장 분야: [`expansion-data.js`](./expansion-data.js)
- 영문 번역: [`translations.js`](./translations.js)
- 배포: GitHub Actions를 통한 GitHub Pages

## 현재 범위

- 13개 학문 대분야
- 129개 세부분야
- 524개 열린 연구문제
- 31개 불가능·현실 경계 사례
- 61개 기관·로드맵·데이터 출처

## 분류 체계

각 항목은 서로 독립적인 세 축을 가집니다.

1. **학문 분야** — 물리학, 화학, 생물학, 재료공학, 반도체·전자공학, 수학·통계학, 컴퓨터과학·AI, 지구·환경과학, 의학·보건과학, 기계·항공·로봇, 인지과학·심리학, 농업·식품과학, 사회·경제·복잡계
2. **필요한 해결 방식** — 이론 중심, 실험 중심, 이론+실험, 공학·시스템
3. **문제 성격** — 근본 원리, 예측·모델, 관측·계측, 확장·재현, 설계·시스템, 불가능 경계
4. **가능성 경계** — 해결 가능성 열림, 현재 기술로 불가능, 현실적 한계, 이론적 불가능
5. **횡단 주제** — 에너지, 우주, 양자, 기후, AI, 지속가능성, 건강, 안전·보안

모든 난제 제목·세부분야·설명과 화면 인터페이스를 한국어 또는 영어로 전환할 수 있습니다.

> **주의:** ‘이론적 불가능’은 미해결 문제의 동의어가 아닙니다. 현재 확립된 법칙·정리 또는 소실된 정보가 금지하는 요구를 별도의 경계 사례로 표시한 것입니다.

## 탐색 기능

- 분야별 막대 차트를 문제 성격, 해결 방식, 가능성의 세 색상 기준으로 전환할 수 있습니다.
- 막대 구간과 범례를 선택하면 해당 분류로 카탈로그가 즉시 좁혀집니다.
- 횡단 주제 필터로 서로 다른 학문에 걸친 문제를 함께 탐색할 수 있습니다.
- 한국어·English 전환 상태와 모든 필터를 URL에 보존합니다.
- 막대 구간, 범례, 난제 카드에 마우스를 올리거나 키보드로 초점을 맞추면 제목과 간략한 설명이 표시됩니다.

## 로컬에서 보기

별도 빌드 도구나 외부 라이브러리가 필요 없습니다.

```bash
python -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다.

## 검증

```bash
npm test
```

검증 스크립트는 항목 수, 고유 ID, 분류값, 출처 참조, 불가능 경계의 분리 및 필수 사이트 파일을 검사합니다.

## 기여 원칙

새 난제를 추가할 때는 질문형 문장, 세부분야, 해결 방식, 문제 성격, 가능성, 관련 출처, 열린 이유와 해결 기준을 함께 기록해 주세요. 분류는 학계의 단일 합의가 아니라 탐색을 돕는 편집적 판단이므로, 변경 제안에는 근거를 남기는 것을 권장합니다.
