# Unsolved Problems

물리학, 화학, 생물학, 재료공학, 반도체·전자공학의 미해결 문제를 여러 축으로 탐색하는 공개 카탈로그입니다.

- 사이트: <https://eljja.github.io/UnsolvedProblems/>
- 데이터: [`data.js`](./data.js)
- 배포: GitHub Actions를 통한 GitHub Pages

## 현재 범위

- 5개 학문 대분야
- 65개 세부분야
- 300개 열린 연구문제
- 15개 불가능·현실 경계 사례
- 30개 기관·로드맵·데이터 출처

## 분류 체계

각 항목은 서로 독립적인 세 축을 가집니다.

1. **학문 분야** — 물리학, 화학, 생물학, 재료공학, 반도체·전자공학
2. **필요한 해결 방식** — 이론 중심, 실험 중심, 이론+실험, 공학·시스템
3. **가능성 경계** — 해결 가능성 열림, 현재 기술로 불가능, 현실적 한계, 이론적 불가능

문제의 성격은 근본 원리, 예측·모델, 관측·계측, 확장·재현, 설계·시스템, 불가능 경계로 추가 구분합니다.

> **주의:** ‘이론적 불가능’은 미해결 문제의 동의어가 아닙니다. 현재 확립된 법칙·정리 또는 소실된 정보가 금지하는 요구를 별도의 경계 사례로 표시한 것입니다.

## 로컬에서 보기

별도 빌드 도구나 외부 라이브러리가 필요 없습니다.

```bash
python -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다.

## 검증

```bash
npm test
```

검증 스크립트는 항목 수, 고유 ID, 분류값, 출처 참조, 불가능 경계의 분리 및 필수 사이트 파일을 검사합니다.

## 기여 원칙

새 난제를 추가할 때는 질문형 문장, 세부분야, 해결 방식, 문제 성격, 가능성, 관련 출처, 열린 이유와 해결 기준을 함께 기록해 주세요. 분류는 학계의 단일 합의가 아니라 탐색을 돕는 편집적 판단이므로, 변경 제안에는 근거를 남기는 것을 권장합니다.
