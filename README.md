# Unsolved Problems

자연과학, 수학, 공학, 의학, 인지과학과 사회과학의 미해결 문제를 여러 축으로 탐색하는 한·영 공개 카탈로그입니다.

- 사이트: <https://eljja.github.io/UnsolvedProblems/>
- 기본 데이터: [`data.js`](./data.js)
- 확장 분야: [`expansion-data.js`](./expansion-data.js)
- 영문 번역: [`translations.js`](./translations.js)
- 근거 중심 우선과제 확장: [`priority-data.js`](./priority-data.js)
- 공식 상금·연구경진 데이터: [`prize-data.js`](./prize-data.js)
- 확장 설명·대표 시도·최근 연구 흐름: [`research-context.js`](./research-context.js)
- 문제별 해결 시도 설계: [`solution-context.js`](./solution-context.js)
- 문제별 가설 경쟁·불확실성 예산·실행 프로그램: [`deep-solution-context.js`](./deep-solution-context.js)
- 별도 연구 페이지: [`solve.html`](./solve.html)
- 검색 색인: [`sitemap.xml`](./sitemap.xml), [`robots.txt`](./robots.txt)
- 배포: GitHub Actions를 통한 GitHub Pages

## 현재 범위

- 13개 학문 대분야
- 207개 세부분야
- 713개 열린 연구문제
- 31개 불가능·현실 경계 사례
- 163개 핵심 난제와 130개 로드맵 우선과제
- 16개 상금 연계 항목(현재 상금·경진 16개)
- 10개 상금 프로그램과 83개 기관·로드맵·데이터 출처

상금 정보는 2026년 8월 5일, 출처 연결·확장 설명·연구 맥락은 2026년 8월 7일 기준으로 검토했습니다. 각 항목은 검증 가능한 질문, 현재까지 축적된 지식, 기술적 병목, 해결 판정 기준과 관련 출처를 함께 기록합니다.

Google 소유권 확인 메타 태그, canonical URL, 한국어·영문 `hreflang`, 문제별 구조화 데이터와 1,490개 현지화 URL의 사이트맵을 제공합니다. 사이트맵은 `npm run sitemap`으로 현재 카탈로그에서 다시 생성할 수 있습니다.

상금은 **증명·반례 상금**, **성능 목표형 연구경진 총상금**, **계산 도전 상금**, **현재 지급을 보증할 수 없는 역사적 제안**을 구분해 기록합니다. 진행 중인 경진이라도 신규 참가 접수가 끝났을 수 있으며, 총상금은 한 문제에 지급되는 금액과 다를 수 있으므로 상세 규정을 반드시 확인해야 합니다.

## 분류 체계

각 항목은 서로 독립적인 여섯 축을 가집니다.

1. **학문 분야** — 물리학, 화학, 생물학, 재료공학, 반도체·전자공학, 수학·통계학, 컴퓨터과학·AI, 지구·환경과학, 의학·보건과학, 기계·항공·로봇, 인지과학·심리학, 농업·식품과학, 사회·경제·복잡계
2. **필요한 해결 방식** — 이론 중심, 실험 중심, 이론+실험, 공학·시스템
3. **문제 성격** — 근본 원리, 예측·모델, 관측·계측, 확장·재현, 설계·시스템, 불가능 경계
4. **가능성 경계** — 해결 가능성 열림, 현재 기술로 불가능, 현실적 한계, 이론적 불가능
5. **횡단 주제** — 에너지, 우주, 양자, 기후, AI, 지속가능성, 건강, 안전·보안
6. **선정 중요도** — 핵심 난제, 로드맵 우선과제, 주요 프런티어, 불가능 경계

모든 난제 제목·세부분야·설명과 화면 인터페이스를 한국어 또는 영어로 전환할 수 있습니다.

> **주의:** ‘이론적 불가능’은 미해결 문제의 동의어가 아닙니다. 현재 확립된 법칙·정리 또는 소실된 정보가 금지하는 요구를 별도의 경계 사례로 표시한 것입니다.

## 탐색 기능

- 분야별 막대 차트를 문제 성격, 해결 방식, 가능성, 중요도의 네 색상 기준으로 전환할 수 있습니다.
- 막대 구간과 범례를 선택하면 해당 분류로 카탈로그가 즉시 좁혀집니다.
- 횡단 주제 필터로 서로 다른 학문에 걸친 문제를 함께 탐색할 수 있습니다.
- 상금 필터로 현재 유효한 상금·연구경진과 역사적 상금 제안을 구분해 볼 수 있습니다.
- 상금 연계 카드에는 금액 배지가 표시되며, 상세 창에서 전체 상금액·금액의 성격·주관기관·지급 조건·공식 규정과 확인일을 볼 수 있습니다.
- 한국어·English 전환 상태와 모든 필터를 URL에 보존합니다.
- 막대 구간, 범례, 난제 카드에 마우스를 올리거나 키보드로 초점을 맞추면 제목과 간략한 설명이 표시됩니다.
- 각 상세 창은 쉬운 문제 정의에서 시작해 현재까지 알려진 것, 기술적 병목과 구체적인 해결 판정까지 한 흐름으로 설명합니다.
- 축적된 연구 프로그램 3개와 현재 연구 방향 3개는 무엇을 시험하는지, 어디까지 진전했는지, 무엇이 아직 부족한지를 문제별로 설명합니다.
- 여섯 개 연구 카드는 해당 난제의 기관·로드맵·난제 목록·상금 규정 가운데 어떤 종류의 근거에 연결되는지 표시합니다.
- 모든 상세 창에서 별도의 해결 시도 페이지로 이동하고, 기존 필터·언어 상태가 보존된 원래 지도 위치로 돌아올 수 있습니다.
- 해결 시도 페이지는 문제마다 우선 검증할 경로와 대안 경로 2개를 제시하며, 기존 연구와 다른 점, 검증 설계, 첫 결정적 시험, 성공 신호, 중단 조건과 필요한 기반을 함께 명시합니다.
- 아이디어를 판정 가능한 질문에서 독립 검증까지 운반하는 5개 연구 관문과 설계 질문, 피해야 할 함정, 안전·윤리 경계를 제공합니다. 제안은 검토된 연구 방향의 시험 가능한 재조합이며 문헌상 최초나 문제 해결을 주장하지 않습니다.

## 로컬에서 보기

별도 빌드 도구나 외부 라이브러리가 필요 없습니다.

```bash
python -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다.

## 검증

```bash
npm test
```

검증 스크립트는 고유 ID, 한·영 질문, 중요도, 검토일, 선정 근거, 출처 참조, 상금 상태·액수·유형·규정 링크, 문제별 현재 지식·기술적 병목·해결 판정, 연구 프로그램 3개와 현재 방향 3개의 개별성, 해결 제안 3개와 연구 관문 5개의 양언어·개별성, 중단 조건·안전 경계, 불가능 경계의 분리 및 필수 사이트 파일을 검사합니다.

## 기여 원칙

새 난제를 추가할 때는 질문형 문장, 세부분야, 중요도, 해결 방식, 문제 성격, 가능성, 검토일, 선정 근거, 관련 출처, 열린 이유와 해결 기준을 함께 기록해 주세요. 상금이 있으면 주관기관의 공식 페이지, 상태, 금액의 성격, 지급·참가 조건도 기록해야 합니다. `research-context.js`가 확장 맥락과 여섯 개 연구축을, `solution-context.js`가 검증 제안과 연구 관문을, `deep-solution-context.js`가 최소 진전 기준·병목 사슬·경쟁 가설·작업 패키지·불확실성 예산·판정 트리를 생성합니다. 특정 문제에 더 적합한 접근은 근거와 함께 명시적으로 보강할 수 있습니다.
