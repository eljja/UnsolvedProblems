6. **선정 중요도** — 핵심 난제, 로드맵 우선과제, 주요 프런티어, 불가능 경계

모든 난제 제목·세부분야·설명과 화면 인터페이스를 한국어 또는 영어로 전환할 수 있습니다.

> **주의:** ‘이론적 불가능’은 미해결 문제의 동의어가 아닙니다. 현재 확립된 법칙·정리 또는 소실된 정보가 금지하는 요구를 별도의 경계 사례로 표시한 것입니다.

## 탐색 기능

- 분야별 막대 차트를 문제 성격, 해결 방식, 가능성, 중요도의 네 색상 기준으로 전환할 수 있습니다.
- 막대 구간과 범례를 선택하면 해당 분류로 카탈로그가 즉시 좁혀집니다.
- 횡단 주제 필터로 서로 다른 학문에 걸친 문제를 함께 탐색할 수 있습니다.
- 상금 필터로 현재 유효한 상금·연구경진과 역사적 상금 제안을 구분해 볼 수 있습니다.
- 상금 연계 카드에는 금액 배지가 표시되며, 상세 창에서 전체 상금액·금액의 성격·주관기관·지급 조건·공식 규정과 확인일을 볼 수 있습니다.
- 한국어·English 전환 상태와 모든 필터를 URL에 보존합니다.
- 막대 구간, 범례, 난제 카드에 마우스를 올리거나 키보드로 초점을 맞추면 제목과 간략한 설명이 표시됩니다.
- 각 상세 창은 쉬운 문제 정의에서 시작해 현재까지 알려진 것, 기술적 병목과 구체적인 해결 판정까지 한 흐름으로 설명합니다.
- 축적된 연구 프로그램 3개와 현재 연구 방향 3개는 무엇을 시험하는지, 어디까지 진전했는지, 무엇이 아직 부족한지를 문제별로 설명합니다.
- 여섯 개 연구 카드는 해당 난제의 기관·로드맵·난제 목록·상금 규정 가운데 어떤 종류의 근거에 연결되는지 표시합니다.
- 모든 상세 창에서 별도의 해결 시도 페이지로 이동하고, 기존 필터·언어 상태가 보존된 원래 지도 위치로 돌아올 수 있습니다.
- 해결 시도 페이지는 문제마다 우선 검증할 경로와 대안 경로 2개를 제시하며, 기존 연구와 다른 점, 검증 설계, 첫 결정적 시험, 성공 신호, 중단 조건과 필요한 기반을 함께 명시합니다.
- 아이디어를 판정 가능한 질문에서 독립 검증까지 운반하는 5개 연구 관문과 설계 질문, 피해야 할 함정, 안전·윤리 경계를 제공합니다. 제안은 검토된 연구 방향의 시험 가능한 재조합이며 문헌상 최초나 문제 해결을 주장하지 않습니다.

## 기여 원칙

새 난제를 추가할 때는 질문형 문장, 세부분야, 중요도, 해결 방식, 문제 성격, 가능성, 검토일, 선정 근거, 관련 출처, 열린 이유와 해결 기준을 함께 기록해 주세요. 상금이 있으면 주관기관의 공식 페이지, 상태, 금액의 성격, 지급·참가 조건도 기록해야 합니다. `research-context.js`가 확장 맥락과 여섯 개 연구축을, `solution-context.js`가 검증 제안과 연구 관문을, `deep-solution-context.js`가 최소 진전 기준·병목 사슬·경쟁 가설·작업 패키지·불확실성 예산·판정 트리를 생성합니다. `research-cycle-data.js`는 최신 원 연구에 근거한 심층 기록과 문제 간 변수 대응·연결 한계·최소 검증을 축적합니다. 특정 문제에 더 적합한 접근은 근거와 함께 명시적으로 보강할 수 있습니다.
